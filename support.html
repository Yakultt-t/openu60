需要什么

  • 一台中兴 U60 Pro（MU5250）5G 随身 Wi-Fi。
  • 路由器上装好开源的 OpenU60 程序。安装方法见 GitHub 上的说明，用 Mac 上的安装助手几步就能装好。
  • iPhone、iPad 运行 iOS 26 或更新版本。

没有路由器也可以先试用：在 App 第一屏点「没有路由器？体验演示模式」，所有功能都用示例数据展示。

常见问题

App 找不到路由器

先让 iPhone 连上路由器的 Wi-Fi（或和路由器在同一个家庭 Wi-Fi 里），并在「设置 → 隐私与安全性 → 本地网络」里允许 SIM 随行。第一次配对后，在外面也能通过加密通道连回路由器。

收不到短信或来电通知

在 App 的「设置 → 通知」里确认这台设备打开了对应的通知，并在 iOS「设置 → 通知 → SIM 随行」里允许通知。路由器需要能上网才能发出通知。

通话有杂音或断续

在外面使用时通话会经过加密中继，网络较差时会受影响。在「设置 → 设备与配对」里可以查看当前连接路径。

通话录音

录音只保存在你的 iPhone 上。各地法律对通话录音的要求不同，录音前请按当地法律告知对方。

Support

What you need

  • A ZTE U60 Pro (MU5250) 5G mobile Wi-Fi router.
  • The open-source OpenU60 agent installed on the router. See the instructions on GitHub; the Mac installer does it in a few steps.
  • An iPhone or iPad with iOS 26 or later.

No router yet? Tap "No router? Try the demo" on the first screen to try every feature with sample data.

Common questions

The app can't find the router

Join the router's Wi-Fi (or the same home Wi-Fi as the router) and allow SIM Go under Settings → Privacy & Security → Local Network. After pairing once, the app reaches the router from anywhere through an encrypted tunnel.

No notifications for messages or calls

Check Settings → Notifications in the app for this device, and allow notifications for SIM Go in iOS Settings. The router needs an internet connection to send them.

Call recording

Recordings are kept only on your iPhone. Laws on recording calls differ by place; tell the other party when the law requires it.
